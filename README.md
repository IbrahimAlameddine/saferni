
# Safarni — Tourism Website

Safarni is a responsive tourism website that helps users explore tourist destinations and discover travel tours in Egypt and Istanbul.

## Features

- Responsive homepage
- Tourism landing pages for Egypt and Istanbul
- Image galleries
- Login and registration pages
- Arabic interface with RTL layout

## Technologies

- HTML5
- CSS3
- Sass (SCSS)
- Bootstrap
- JavaScript
- Webpack
- Git and GitHub

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/IbrahimAlameddine/saferni.git
```

### 2. Open the project folder

```bash
cd saferni
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

Open the local URL displayed in your terminal.
